# Sun Liquor & Grocery — Website

Single-page site for Sun Liquor & Grocery, 12 Kearny Ave, Kearny, NJ.

## Preview
Open `sun-liquor-website.html` in a browser. No build step, no dependencies.

## Editing
- **Hours:** update both the hours grid and the footer (they're duplicated).
- **Colors:** CSS variables in `:root` at the top of the file.
- **Links:** DoorDash, Apple Maps, Instagram (currently a placeholder `#`).

## Deploy
Any static host (GitHub Pages, Netlify, Cloudflare Pages). Rename the file to `index.html` first.
